# Agora RTT Demo

A real-time transcription demo application built with Agora's RTT (Real-Time Transcription) service, showcasing live speech-to-text capabilities in a modern web application.

### Overview
This demo showcases real-time speech-to-text transcription capabilities using Agora's RTT service. It provides a practical example of implementing live transcription in a web application, making it easier for developers to understand and integrate Agora's RTT features.

### Features
- Real-time speech-to-text transcription
- Multi-language support
- Modern web interface
- Real-time communication capabilities
- Secure token-based authentication

### Tech Stack
#### Backend
- Go 1.20+
- Gin Web Framework
- Agora Dynamic Key Generation
- Viper for configuration management
- Zap for logging
- RESTful API design

#### Frontend
- React 18
- TypeScript
- Vite
- Ant Design
- Agora RTT SDK
- Redux for state management
- i18next for internationalization
